# 成人版MVP — 前端组件规格

> 版本：v1.0 | 日期：2026-07-25
> 基于：PM v3 三层展示设计 + 三段式第一次行动 + 同心圆反馈
> 页面流：诊断页 → 结果页 → 今日可做 → 过渡页 → W1入口

---

## 一、页面流程

```
/diagnosis/adult/start → 答题页（20题） → 结果页（8维三层雷达）
                                                    ↓
                                       ┌──────────────┴──────────────┐
                                       ↓                             ↓
                                🆓 今日可做（三段式）           🔒 付费报告入口
                                       ↓
                                  过渡页（15秒）
                                       ↓
                              (隔天推送) W1行动卡入口
```


**规格**：
- 题干文字：18px, color #1a1a1a, line-height 1.6
- 选项文字：16px, color #333, padding 12px 16px
- 选中状态：bg #e8f4fd, border-left 3px solid #3b82f6
- 选项悬停：bg #f5f5f5 (desktop only)
- 进度条：W3C `<progress>` 或自定义bar, #3b82f6
- 每个选项点击后锁定，不可修改（no going back）
- 最底部：浮层进度 + "还有X题完成诊断" 文字

**间距**：
- 卡片内 padding: 24px
- 选项间距: 8px
- 选项与按钮间距: 20px

### 3.2 8维条形图规格 (DimensionBar)

每个维度渲染为一行，三层之间用10px间距分隔并用浅灰色标签分隔：

```css
.layer-bar {
  background: #f0f0f0;         /* 层标签背景 */
  padding: 6px 12px;
  font-size: 13px;
  color: #666;
  font-weight: 600;
  border-radius: 4px;
  margin-bottom: 8px;
}
```

每条维度条：

```css
.dimension-row {
  display: flex;
  align-items: center;
  gap: 12px;
  padding: 8px 12px;
  margin-bottom: 4px;
}
.dimension-name {
  width: 100px;               /* 维度名固定宽 */
  font-size: 14px;
  color: #333;
  font-weight: 500;
}
.dimension-bar-bg {
  flex: 1;
  height: 12px;
  background: #e5e7eb;
  border-radius: 6px;
  overflow: hidden;
}
.dimension-bar-fill {
  height: 100%;
  border-radius: 6px;
  transition: width 0.8s ease;
}
.dimension-score {
  width: 40px;                /* 分数固定宽 */
  text-align: right;
  font-size: 14px;
  font-weight: 600;
  color: #1a1a1a;
}
```

**颜色映射**：

| 得分区间 | 颜色 | 语义 | 对应标签 |
|:-------:|:----:|:----:|:--------:|
| 0-30 | #ef4444 (red) | 待提升 | needs_improvement |
| 31-55 | #f59e0b (amber) | 有空间 | needs_improvement |
| 56-75 | #3b82f6 (blue) | 良好 | good |
| 76-100 | #22c55e (green) | 优秀 | excellent |

**第8维AI元认知特殊标记**：
- 条形图使用 **虚线边框** 而非纯色填充：`border: 2px dashed`
- 条形后显示 ⭐ 标记
- 标签多一行灰色小字："对内：自我觉察的能力"
- 第8维色条用 `#8b5cf6` (紫色) 以区别于其他7维的蓝色系

**每层总分显示**：
- 本层×维度得分的平均值，只展示为文字不展示为条形
- 后面显示 "█" 进度，占宽比例 = 平均分/100

### 3.3 短板标记

```typescript
interface WeaknessHighlight {
  dimensionId: string;
  layer: 'base' | 'advanced' | 'leadership';
  score: number;
  isWeakest: boolean;     // 是否为最低分维度
  suggestion: string;     // 一句行动建议
}
```

- 最低分维度标记 ⚠️ 图标
- 该维度条形闪烁一次（2秒动画）
- 下方显示：`你最大的成长空间：AI元认知（38分），建议从'今日可做'开始`

## 四、三段式第一次行动（Step by Step 组件）

### Step 1：复制Prompt → 粘贴 → 确认

用户点击 "开始第一次行动" 后：

```
┌────────────────────────────────────────────────┐
│  👣 第一步（1分钟）                              │
│                                                   │
│  📝 复制这段文字：                                │
│  ┌─────────────────────────────────────────┐    │
│  │  "用一句话总结2026年AI对我的职业意味着什么" │    │
│  │                                   [📋复制] │    │
│  └─────────────────────────────────────────┘    │
│                                                   │
│  1. 点 "复制"                                    │
│  2. 打开你的AI工具（ChatGPT/豆包/文心等）         │
│  3. 粘贴进去 → 回车                               │
│  4. 回来点 "✅ 已完成"                            │
│                                                   │
│  [✅ 我已完成第一步]                                │
└────────────────────────────────────────────────┘
```

**状态流转**：
- 初始：灰色按钮（不可点击）
- 点击复制后：按钮变为蓝色（可点击） + 文案 "已复制，去AI工具粘贴体验吧"
- 点击 "我已完成第一步"：进入过渡页

### Step 2 和 Step 3（可选择，不强制）

Step 2 在过渡页下方 "你还可试试" 折叠区域：

```
[▼ 你还可试试 — 换一种问法]
┌────────────────────────────────────────────────┐
│  想看看不同AI的回答？试试这个问法：              │
│  "用三个词描述AI对我的职业影响，各有1个例子"      │
│                                              [📋复制] │
└────────────────────────────────────────────────┘
```

Step 3 在更下方折叠区域：

```
[▼ 进阶 — 发朋友圈看反应]
┌────────────────────────────────────────────────┐
│  分享你的发现到朋友圈？                         │
│  (匿名，只显示雷达图轮廓)                       │
│                                              [分享] │
└────────────────────────────────────────────────┘
```

**重要**：Step 3 分享的内容是 **雷达图轮廓匿名版**（不显示具体分数和名字），而非"我的短板是XX"。这是student模拟验证后的修正方向。
