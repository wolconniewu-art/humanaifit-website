# 儿童版 "AI未来星" v3.0 — 技术规格

> 版本：v1.0 | 日期：2026-07-25
> 基于：产品迭代实施方案 — 儿童版规格 + globe中英文维度命名体系
> 状态：MVP已入库（11题），规划50题

---

## 一、产品规格

| 维度 | 规格 |
|------|------|
| 目标用户 | 家长（决策者）+ 6-18岁孩子（使用者） |
| 诊断形式 | 10-15题选择题 → **5维雷达图** |
| MVP题量 | 11题（已入库：cognitive_core 3题、practice_innovation 2题、social_emotion 2题、aesthetic_humanity 2题、digital_basics 2题） |
| 完整题量 | 50题（5维×每维10题：简单3+中等4+复杂2+备用1） |
| 结果展示 | 5维雷达图（替代当前3类标签）+ 成长空间标记 + 30天行动卡 |
| 付费报告 | ¥9.9 → 完整报告PDF（含30天行动卡+适龄工具推荐） |
| 持续成长 | 30天日模式（每天1任务）→ 60天周任务 → 季度深化 |
| 核心场景 | 家长搜索"孩子该学什么AI" → 10分钟诊断 → 雷达图 → 30天行动卡 |
| 版本路线 | v2.x（当前3类标签）→ **v3.0（5维雷达图+30天行动卡）** → v4.0（训练营推荐+持续学习追踪） |

## 六、评分器算法

同成人版加权算法，但使用 `ChildScorer`（已入库）：

```typescript
class ChildScorer extends Scorer {
  // 5维加权
  // weight = easy × 1.0 + medium × 1.5 + hard × 2.0
  // dimensionScore = Σ(题得分 × weight) / Σ(maxScore × weight) × 100
  // overallScore = 5维平均
}
```
