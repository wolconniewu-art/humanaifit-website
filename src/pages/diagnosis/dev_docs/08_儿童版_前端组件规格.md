## 二、答题页组件

### 2.1 儿童版题目卡片 (ChildQuestionCard)

```
┌──────────────────────────────────────────────┐
│  第 3/10 题            ⭐ 星星进度 ████░░░░  │
├──────────────────────────────────────────────┤
│                                               │
│  AI说「明天会下雨」，但窗外是晴天。              │
│  你会怎么做？                                  │
│                                               │
├──────────────────────────────────────────────┤
│                                               │
│  ○ A. 相信AI，带伞出门                        │
│  ● B. 打开手机天气APP对比一下                  │
│  ○ C. 怀疑AI出错了，不信它了                   │
│  ○ D. 不知道该信谁                           │
│                                               │
├──────────────────────────────────────────────┤
│              [上一题]     [下一题]              │
└──────────────────────────────────────────────┘
```

**差异点（对比成人版）**：
- 星星进度条（⭐）替代纯数字进度——更趣味化
- 字体 16-18px（成人版14px）——儿童要看清
- 选项按钮更大（padding 14px vs 12px）——方便手指点击
- 选项选中后如果孩子想改，允许后退修改（不锁定）
- 题号显示简化："第 3/10 题" 而非 "第3/10题"（加空格间隔清晰）
