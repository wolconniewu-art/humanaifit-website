# 老年人版 — 前端组件规格

> 版本：v1.0 | 日期：2026-07-25
> 页面流：入口页 → 场景选择 → 视频播放 → 完成确认 → 子女端推送

---

## 一、页面流程

```
入口页（女儿发链接） → 场景选择页（4个大图标） → 确认选择
                                                      ↓
                                              60秒视频播放页
                                                      ↓
                                              完成确认页
                                              ├── 发家庭群
                                              └── 推子女微信
```

**设计规范（必须遵守）**：
- 所有字体 ≥ 24px（老年人视力）
- 高对比度：文字 #000000 或 #1a1a1a，背景 #ffffff
- 按钮触摸区域 ≥ 64×64px
- 一屏显示完整4个选项，无需滚动
- 不使用蓝色链接文字（老年人可能不知道可以点）
- 每个选项用大图标➕大文字➕一行极短说明
- 背景柔和（#fafafa），不刺眼

**视频播放器组件规格**：

```css
.video-player {
  width: 100%;
  max-width: 400px;
  aspect-ratio: 9 / 16;        /* 竖屏 */
  margin: 0 auto;
  background: #000;
  border-radius: 12px;
}
.video-controls {
  display: flex;
  justify-content: space-between;
  padding: 8px 16px;
  font-size: 20px;              /* 大按钮 */
  color: #fff;
}
.video-step-indicator {
  font-size: 22px;
  color: #1a1a1a;
  text-align: center;
  padding: 8px 0;
  line-height: 1.5;
}
```

**交互要求**：
- 视频自动适配屏幕宽度，无需手动全屏
- 视频下方显示当前步骤的三步文字指引
- "做完了"按钮在视频播放完后高亮可点击
- 如果用户中途退出，记录播放进度（下次从断点续看）
- 视频底部有大号重放按钮（文字"再看一遍"而非小图标）

## 七、推送策略时间线（前端侧）

### 7.1 首次完成→子女推送

```typescript
// 用户点击"我做完了"后立即触发
function onScenarioCompleted(userId: string, scenarioId: string) {
  // 1. 保存完成记录到 diagnosis_answers
  saveCompletion(userId, scenarioId, new Date());
  
  // 2. 触发微信模板消息（调后端接口）
  await sendWechatTemplate(userId, {
    template: 'scenario_completed',
    data: {
      parentName: getParentName(userId),
      scenarioTitle: getScenarioTitle(scenarioId),
      imageUrl: getCompletionImage(userId, scenarioId),
    },
  });
  
  // 3. 启动2小时计时器（后端cron或worker）
  await scheduleNoReplyCheck(userId, 2 * 60 * 60 * 1000);
}
```

### 7.2 推送状态机

```
完成1个场景
    ↓
推子女微信
    ↓
┌── 2小时内子女回复？ ── 是 ──→ 3天后推下一个场景
│
└── 否 ──→ 二次提醒
                ↓
┌── 24小时内子女回复？ ── 是 ──→ 3天后推下一个场景
│
└── 否 ──→ 暂停推送，写日志
                ↓
子女返回产品/回复消息后 → 恢复推送
```
